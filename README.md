# Undangan Pernikahan Dafa & Taniyah

Aplikasi undangan pernikahan digital interaktif untuk Dafa Adi Raharjo dan Taniyah Rahman. Dibuat dengan Next.js App Router, React, TypeScript, Tailwind CSS, Framer Motion, Supabase, dan Google Gemini.

## Fitur

- Sampul undangan dengan nama tamu yang dapat diisi lewat parameter URL `to`, misalnya `/?to=Nama%20Tamu`.
- Hitung mundur menuju acara pada 23 Mei 2027.
- Informasi mempelai, kisah pasangan, galeri foto, dan detail acara.
- Kontrol musik latar.
- RSVP dan buku ucapan yang tersimpan di Supabase serta diperbarui secara realtime.
- Pemolesan ucapan dengan Google Gemini.
- Dashboard admin di `/admin` untuk melihat statistik RSVP, mencari ucapan, dan menghapus entri.

## Menjalankan Secara Lokal

Prasyarat: Node.js dan npm.

1. Pasang dependensi:

   ```bash
   npm install
   ```

2. Buat file `.env.local` di direktori proyek dan isi variabel yang diperlukan (lihat bagian [Konfigurasi](#konfigurasi)).
3. Jalankan server pengembangan:

   ```bash
   npm run dev
   ```

4. Buka [http://localhost:3000](http://localhost:3000).

Perintah lain yang tersedia:

```bash
npm run lint
npm run build
npm run start
```

## Konfigurasi

```env
NEXT_PUBLIC_SUPABASE_URL=https://PROJECT_ID.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=SUPABASE_ANON_KEY
GEMINI_API_KEY=GEMINI_API_KEY
```

`NEXT_PUBLIC_SUPABASE_URL` dan `NEXT_PUBLIC_SUPABASE_ANON_KEY` diperlukan untuk koneksi Supabase. `GEMINI_API_KEY` diperlukan untuk fitur pemolesan ucapan dengan AI; jika layanan AI gagal, aplikasi menggunakan ucapan asli.

Jangan masukkan kredensial asli ke README atau commit file `.env.local` ke repositori.

## Menyiapkan Supabase

Buat tabel `public.wishes` dengan kolom yang digunakan aplikasi. Contoh skema:

```sql
create table public.wishes (
  id bigint generated by default as identity primary key,
  name text not null,
  attendance text not null,
  wish text not null,
  created_at timestamptz not null default now()
);
```

Atur kebijakan akses Supabase agar operasi yang diperlukan aplikasi (membaca, menambahkan, dan menghapus ucapan) diizinkan sesuai kebutuhan deployment. Aktifkan Realtime untuk tabel `wishes` agar pembaruan RSVP tampil tanpa memuat ulang halaman.

## Catatan Keamanan

Halaman `/admin` saat ini belum memiliki autentikasi atau pembatasan akses. Jangan publikasikan dashboard ini sebelum akses admin dilindungi. Kebijakan database juga perlu disesuaikan dengan model keamanan aplikasi sebelum digunakan di produksi.

## Struktur Penting

- `app/page.tsx`: halaman undangan dan interaksi tamu.
- `app/admin/page.tsx`: dashboard RSVP.
- `app/actions.ts`: operasi buku tamu, penghapusan ucapan, dan integrasi Gemini.
- `lib/lib/supabase.ts`: klien Supabase.
- `public/`: foto, gambar, QR, serta aset musik undangan.
